We are finishing the frontend of an existing project called Research Desk.

IMPORTANT: Work on the existing codebase connected from GitHub. Do not rebuild the application from scratch.

ABOUT THE PRODUCT

Research Desk is a simple "Research Operating System" designed for organizing research, ideas, projects and long-term thinking.

The core hierarchy is:

Organization Desk
→ Project
→ Branch
→ Child Branch

A Project contains project notes and branches.

A Branch contains notes, child branches, files and links.

A Child Branch contains notes, files and links.

The philosophy is:
simple workflow, minimal clutter, strong organization.

This is NOT meant to become Notion, Obsidian or a general-purpose productivity suite.

CURRENT STATE

- Complete basic frontend/UI
- Project/branch/child-branch navigation
- Breadcrumbs
- Files and links
- Delete confirmations

- Dark desktop-style interface
